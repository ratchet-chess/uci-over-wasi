# Adapted engines

Each folder in this directory contains edits, a pin file, a build script, and provenance metadata for one upstream chess engine adapted to UCI over WASI.

Unlike the rest of this repository (which is under the MIT License in `../LICENSE`), each folder under `adapted/` is licensed under its upstream engine's own license, stated in that folder's `pin` file. `COPYING` contains the text of the GNU General Public License, version 3, which is the license of most of these engines.
